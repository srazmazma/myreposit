# myreposit

## Pong Game

Open `index.html` in a browser to play the retro Pong game. Two players can use **W/S** and **↑/↓** to control paddles, **P** to pause, and **R** to reset.

### Run locally

You can open the file directly in your browser, or serve it from a local web server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000/index.html`.
